# ANS Splendor Practice Engine

A practice app for 4-player Splendor (base game): you against three bots, in Thai or English.

**Play:** https://terraran.github.io/ANS_Splendor/

## Features
- Full base game: 90 development cards, 10 nobles, official 4-player rules
- Bot levels: Easy, Medium, Engine (engine building and nobles), Hard
- Coach: shows the best move and explains the target card
- Read the table: what each opponent can buy next turn, and how close they are to each noble
- Six drills with pass marks, a strategy simulator, a game review, and a copyable game log

## Notes
- Practice history and drill progress are saved in each browser and are not shared between devices.
- The card list was typed from memory and checked for counts and point totals, not card by card. Please report any card that differs from the box.

The whole app is the single file `index.html`. To update it, replace that file.
